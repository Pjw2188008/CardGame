# UNKNOWN 다이아 돌파 성능 강화 비교 보고서

검증일 2026-11-11. 지정한 세 카드의 효과 피해량을 적용했고 현재 기본 버전은 DiamondBuff다. DiamondBuff는 하트 하향 전 Revised에서 직접 파생했다. 이전 HeartNerf는 별도 버전으로 보존했다.

## 적용 및 자동 대조

|카드|Revised|DiamondBuff|
|---|---|---|
|♦4|무작위 적 유닛 1명 피해 3|같은 방식으로 피해 4|
|♦7|서로 다른 적 최대 2명에게 각각 피해 2|같은 방식으로 각각 피해 3|
|♦10|선택한 적 유닛 1명 피해 5|같은 방식으로 피해 6|

57종 전수 검사에서 이 세 효과의 수치만 변경됐음을 확인했다. 마나·공격력·기본 HP, 대상 방식·발동 순서·효과 종류와 다른 카드 효과는 Revised와 같다. 세 카드 설명의 피해 숫자도 갱신했다. ♦7은 기존 ChainDamage 경로를 사용한다. 적이 1명이면 한 번만 적용하고 동일한 살아 있는 대상을 중복 선택할 수 없다.

고정 상황과 이전 Revised/HeartNerf 보존 검사 594개를 통과했다. 여기에는 적 0/1/3명, 서로 다른 2대상, 중복 선택 거절, 단일 대상 처치 후 대기 해제, 무작위 피해, 선택 피해 6, 과잉 피해의 실제 HP 상한, 소환 비용 검사가 포함된다. 최종 격리 Unity 컴파일 오류는 0개다.

수정 전 소스와 해시는 diamond_buff_test/baseline_backup에 보존했다. Revised 57종 정의는 Revised-card-data.json으로 별도 저장했다. 원본 AI·맵·전투 처리·UNKNOWN·조커 소스 해시가 동일하고, 변경한 계측 코드는 상세 로그의 대상 카드 정보와 반격 피해를 추가하는 부분에 한정됨을 검사했다. 통계 감사 33,572개 조건을 통과했다. 피해와 처치 로그는 기존 카드 집계에 정확하게 대조했다.

## 실험 설계

DiamondBuff 1,000판과 새 Revised 1,000판을 같은 일정으로 실행했다. 첫 500판은 기존 480개 주 비교 다리와 20개 Random 스트레스를 재사용한다. 다음 500판은 같은 구성에 새 고정 시드를 적용했다. 한 버전당 960개 주 비교는 6맵 각각 160판이며 같은 초기 조건에서 선후공을 교환한다. 40개 스트레스는 Random 대 Random 및 다른 AI와의 대전이다. Aggressive/Control/Effect/Random 네 정책을 모두 포함한다.

초기 덱·손패, AI 정체성·정책 시드, 맵, 선후공 교환, 전투 시드를 1,000쌍 모두 대조했다. 포커 시너지는 실험에서 false다. 일반 플레이의 포커 설정은 기존값을 따른다. 이전 하트 실험에 보관된 Revised 1,000판의 승패·턴·행동 수와 전투/정책 RNG 이력을 전부 재현했고 불일치는 0건이다.

전투 경로가 바뀌면 RNG 소비가 달라진다. 이번 771쌍은 전투 RNG 이력이 달랐다. 같은 초기 시드가 경기 전체의 난수를 완전히 대응시키지는 않는다. 완료 경기만 카드 효과·승률·평균 집계에 포함한다. 미종료 경기의 마지막 상태와 이벤트는 별도로 남긴다.

## 판정과 후속 후보

적 유닛 제거 성능은 세 카드 모두 사용당 처치 기준으로 개선됐다. 전투 속도 개선은 전체 약 0.37% 수준으로 작고 하트 맵에서는 반대 방향이다. 동일 AI 선공 승률이 65.33%까지 증가해 이번 안을 전반적인 균형 개선으로 판정하기 어렵다.

후속 후보는 관측상 처치 증가가 가장 큰 ♦7만 기존 피해 2로 되돌리고 ♦4·♦10 강화만 유지하는 단일 변경 대응 실험이다. 세 카드를 한 번에 바꿔 이번 결과만으로 어느 카드가 선공 편향을 유발했는지 확정할 수 없으므로 한 카드씩 분리 검증해야 한다. 추가 수치는 자동 조정하지 않았다.

## 파일과 실행 범위

결과는 D:/git/ECHO-/Echogame/CardGame/diamond_buff_test/20261111-131451-375에 있다. Revised와 DiamondBuff 하위 폴더에는 기존 형식의 카드/효과/맵/AI/경기 CSV와 요약·후보·메타데이터 JSON, 압축 상세 이벤트를 보존했다. comparison에는 card_performance.csv, diamond_vs_heart.csv, relative_suit_performance.csv, match_comparison.csv, paired_completed_games.csv, card_changes.csv, comparison.json과 감사 목록을 저장했다. 메타데이터의 절대 경로는 격리 실행 당시 경로이며 전달 폴더의 상대 구조를 유지했다.

새 로그의 secondaryAmount는 Attack 이벤트에서 실제 반격 피해이며, targetCardID/targetCardType은 대상 카드 정보다. 분석 결과 schemaVersion은 2.1이다. JSONL 원본은 로컬 Library의 격리 프로젝트에 보관하며 Git에서는 제외한다. 전달한 gzip을 풀어 원본 SHA-256과 일치함을 확인했다.

Unity 메뉴 Tools > UNKNOWN > Run Diamond Buff Comparison으로 Revised 1,000판 후 DiamondBuff 1,000판을 다시 실행할 수 있다. 현재 기본 플레이는 DiamondBuff를 사용한다. 이전 HeartNerf 비교는 명시적 버전 조회로 보존했다. 이번에 Windows EXE 재빌드나 온라인 플레이 검증은 수행하지 않았다.

실제 수정은 CardData.cs의 버전 등록/기본 버전 연결, HeartNerfChecks.cs의 과거 버전 검사 고정, BalanceTelemetry.cs의 관측 필드 추가다. DiamondBuffCardCatalog.cs, DiamondBuffChecks.cs, DiamondBuffBatch.cs를 추가했다. AI와 맵 및 공통 전투 처리 소스는 변경하지 않았다.
