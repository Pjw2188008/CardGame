# UNKNOWN 현재 게임 맵별 AI 대전 결과

실행일: 2026-11-15 KST. 현재 실제 기본값 FullBalanceRework(10)으로 맵마다 정확히 200판, 총 1,200판을 한 번 실행했다. 정상 종료 1191판, 미종료 9판, 오류 0판이다. 추가 재대전이나 다른 프리셋 비교는 하지 않았다.

정상 종료 기준 전체 평균 **23.35 글로벌 턴**, 중앙값 **19**, 최장 **85**이다. 선공 **586승(49.20%)**, 후공 **605승(50.80%)**으로 선후공 승률 차이는 -1.60%p다. 참고 범위인 평균 20~30턴과 선공 45~55%에 전체 결과가 들어간다. 비교 대조군이 없으므로 이번 보정이 이 결과를 인과적으로 만들었다고 단정할 수 없다.

## 실행 조건과 검증

- HP 30, 기본 지급 손패 3장/3장에 후공 자기 덱 저코스트 일반 카드 1장 추가, 손패 상한 8, 필드 5, 기본 마나 3, 마나 상한 10를 사용했다. 선공 경기 첫 드로우 생략과 후공 첫 자기 턴 현재 마나 +1을 포함한다. 이후 맵 효과와 드로우는 실제 엔진 그대로다.
- 초기 지급 이벤트에서 3장/4장, 카드 ID 중복 없음, 후공 마지막 카드의 일반 카드 여부와 비용 2 이하를 **1,200/1,200판** 확인했다. 턴 2 시작 직후 보너스 +1, 지급 전 현재 마나 3을 **1,200/1,200판** 확인했다. 클로버 맵은 그 뒤 기존 맵 +1이 더해져 후공 첫 턴 5마나가 된다. 덱 제거·후보 없음 대체·재지급 방지는 앞선 기능 검증을 그대로 사용했으며 이번에는 검증용 추가 경기를 만들지 않았다.
- 포커 시너지 **활성화**. 기존 테스터 생성자의 강제 false를 첫 Tick 이전 공개 실행 설정에서 실제 게임 값 true로 되돌렸고 실제 생성된 엔진 Config에서도 true를 확인했다. 게임·AI·수집기 코드는 수정하지 않았다. 기존 리포터의 하드코딩된 false 메타데이터는 실행 결과 파일에서만 실제 true로 바로잡았다. 기존 ruleDataSHA256 해시에는 false 리터럴이 들어가므로 포커 활성 근거는 workload.json·effective_maps.json·실제 PokerChanged 이벤트를 함께 사용해야 한다.
- 기존 Random/Aggressive/Control/Effect 정책과 현재 AiObservation·BattleEngine을 사용했다. 각 맵에서 각 AI는 선공 50판·후공 50판씩 참가했다. 100개 조건마다 AI·덱 시드·정책 시드를 교환한 2경기이며 전투 시드는 유지했다. 현재 엔진은 슬롯 0에서 시작하고 온라인 코드는 Host를 슬롯 0으로 연결한다. 별도 무작위 선공 추첨은 현 코드에 없으며 이번 테스트에서도 변경하지 않았다.
- 렌더링 없는 기존 BalanceTestRun/BalanceMatchCollector/BalanceReport를 사용했다. 기존 안전 제한은 1,000턴 또는 20,000행동이며, 회복 불가능한 소진 상태도 미종료로 분류한다. 미종료에 임의 승자를 부여하지 않았다. 승률·전투 길이·카드 통계는 정상 종료 경기만 집계하고 시작 지급 검증은 전체 1,200판을 대상으로 했다.

## 우선 검토할 항목

1. 조커 맵의 선공 56.50%와 평균 18.54턴, 특수 승리 28회를 먼저 검토한다. 현 표본에서는 빠른 종료와 선공 쏠림이 함께 관찰되지만 사건/도박 자체의 인과 효과는 확정할 수 없다.
