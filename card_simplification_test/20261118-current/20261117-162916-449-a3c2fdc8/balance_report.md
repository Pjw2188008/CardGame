# UNKNOWN 일반 카드 52장 효과 단순화 — 적용 및 AI 검증

## A. 실제 적용 결과

현재 기본 `FullBalanceRework` 일반 카드 52장을 2026-11-18 첨부 표의 마나·ATK·HP·효과·설명으로 교체했다. 새 프리셋·프로젝트·씬·게임 모드를 만들지 않았다. 현재 열려 있는 원본 Unity 프로젝트에서 컴파일 및 기존 CardBalanceBatch를 실행했다.
일반 카드의 모든 효과는 배치 직후 기존 대상 선택/손패 선택 절차로 처리된다. 공격·처치·턴 시작·특정 카드 보유 조건부 효과와 일반 클로버의 할인 효과를 데이터에서 제거했다. 영구 공격력/최대 HP 증가, 독립 ATK·HP 약화와 대상 소유자 턴 카운트, 보호, 턴당 추가 마나 +2, 손패 8장 규칙은 기존 처리를 재사용했다.
공통 처리 변경은 ♦7이 약화 여부와 무관하게 적을 선택하여 같은 대상의 보호를 제거하고 피해를 주도록 한 부분과, 현재 클로버 교환 카드가 고정 명시 수량을 드로우하도록 한 부분이다. ♣4/♣9는 남은 손패가 있으면 1장 선택 후 2/3장을 뽑고, 남은 손패가 없으면 버리기를 생략하고 2/3장을 뽑는다. ♣Q는 0~2장을 버린 뒤 항상 3장을 뽑는다. 할인 시스템과 기존 효과 종류는 다른 기능과의 호환을 위해 유지했다.
Unity 6000.0.74f1 런타임·에디터 컴파일 통과. 결정적 효과/호환 검사 376개 통과. 52장 모두 수치·설명·효과 종류·대상·수량·기간을 명세와 비교하고, 실제 소환과 대상 선택 후 필드/손패/마나 결과를 검사했다.

## C. 카드 효과 및 계측 검증

- ♠2/♠7/♠Q/♠A의 대상 소유자 2/3턴 경험 후 해제, 상대 소유자 턴에서 카운트 미감소, 별도 전투 피해 비복구를 확인했다.
- ATK/최대 HP 약화별 -3 상한, 기간 max 갱신, HP 최소 1, 영구 ATK 강화의 독립성, 네트워크 상태 왕복, 싱글 약화 증강 +1턴과 저장 복구를 확인했다.
- ♦7의 보호 제거→같은 대상 피해, ♥K/A의 최대·현재 HP 동시 증가, 보호 최댓값 유지 및 실제 방어량은 실제 상태/기존 계측을 사용한다.
- ♣Q의 0/1/2장 버리기 각각 고정 3장 드로우, ♣4/♣9의 빈 손패 처리, 추가 마나 +2와 자기 턴 리셋, 손패 8장 및 초과 카드 덱 제거/폐기를 확인했다.
- A+J/Q/K 손패 조합을 각각 실행했다. J/Q/K/A는 52장 소환 검사에도 포함된다. UNKNOWN 3장 승리 코드와 조커 도박 코드는 변경하지 않았으며, 이번 자연 대전에서 UNKNOWN 승리는 0회라 발생 빈도가 충분하다고 볼 수 없다.

계측 해석:

- `effectActivations`는 인스턴스·효과 항목별 최초 처리 횟수다. `effectApplications`에는 무대상·무효 처리도 들어가며, `effectSuccesses`는 기존 계측의 0이 아닌 결과 수다. 광역/복합 효과는 한 번 배치해 여러 적용으로 집계된다. 기간만 갱신한 약화는 별도 `attackWeakApplications`/`healthWeakApplications`로 보아야 한다.
- 실제 피해는 `attackDamage`/`effectDamage`(기존 피해 이벤트), 약화량은 `attackWeakReduction`/`healthWeakReduction`, 보호 방어량은 `protectionPrevented`, 추가 마나는 `manaGained`, 회복량은 `healing`을 사용한다. `card_effect_statistics.csv`의 일반 Damage 실제량 칸은 기존 구현상 명목 피해/오버킬을 포함할 수 있으므로 실제 피해의 근거로 쓰지 않는다.
- 드로우는 기존 계측상 실제 손패에 수용된 수량이며 초과 폐기는 `overflowDraws`에 분리된다. 카드 효과별 드로우 시도 총량과 모든 스킵 원인은 세부 로그를 꺼 둔 이번 실행에서 추가로 수집하지 않았다.
- 사용 경기 관측 승률은 그 카드를 사용한 플레이어-경기의 승률이다. 양쪽 모두 사용한 경기는 양쪽 표본에 들어갈 수 있다. 인과적 카드 승률이나 카드 간 공정한 단독 비교가 아니다. 배치 200회 미만은 기존 표본 기준상 부족 표시다.
