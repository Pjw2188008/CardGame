# 카드 단독 확대

2026-11-10 Unity 6000.0.74f1에서 확인했다.

카드 호버 시 확대된 카드만 표시한다. 별도 수치 변화 설명, 어두운 설명 패널 및 외곽선을 제거했다. 카드 자체의 이미지와 현재 마나·공격력·체력·능력 문구는 카드 렌더링을 그대로 사용한다.

포인터 이탈과 소환·공격 드래그 시 닫힘, 원본 카드 클릭 유지, 공개 카드 확대, 화면 경계 제한, 맵·조합 안내 복원을 검사했다. 1280×720과 1920×1080 렌더에서 별도 설명 패널 없이 카드만 보이는 것을 확인했다.

최종 자동 검사 758개 통과, 실패 및 예외 0개. 처음 실행에서 기존 설명창 내용을 기대하는 조커 공개 카드 검사 하나가 실패하여 새 요구사항에 맞춰 검사를 수정하고 전체를 재실행했다. Verification.json에 검사별 결과와 실제 적용한 소스 해시를 기록했다.

이번 검증은 Unity 로컬 UI 및 규칙 검사이며 실제 두 PC의 Relay 연결은 재실행하지 않았다.

Windows Development Build 성공. 오류 0개, 경고 8개. Builds/UNKNOWN-CardOnlyHover/UNKNOWN.exe를 사용하며 폴더 전체가 필요하다. 빌드 원본과 복사본의 게임 DLL 해시가 일치한다.
