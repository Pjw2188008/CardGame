# 맵별 카드 뒷면

2026-11-10 Unity 6000.0.74f1에서 적용했다.

기존 덱 표시와 함께 상대 비공개 손패, 드로우 뒤집기 전 덮개, 손패 초과 드로우와 앞면 정보 없는 폐기 연출에 Assets/CARD/CardBack의 현재 맵 이미지를 사용한다. 숨겨진 손패에 카드 이름과 수치를 생성하지 않는다. 공개 효과의 앞면은 뒷면 위에 유지하고 공개가 끝나면 맵 뒷면이 보인다. 카드 뒷면 그림은 비율을 유지하고 입력을 받지 않는다.

자동 UI 검사 788개 통과, 실패 및 예외 0개. 6개 맵에서 양쪽 플레이어 관점의 손패 뒷면과 카드 정보 숨김을 확인하는 12개 검사를 추가했다. 기존 드로우·초과 폐기·카드 공개·덱 클릭 버리기 검사도 통과했다. 일반/조커 맵의 1280×720 및 1920×1080 렌더를 확인했다.

이번에는 Unity 로컬 검사와 렌더를 사용했다. 실제 두 PC의 Relay 연결 재검증은 수행 범위에 포함하지 않았다.

Windows Development Build 성공. 오류 0개, 경고 8개. Builds/UNKNOWN-AllCardBacks/UNKNOWN.exe를 폴더 전체와 함께 사용한다. 복사한 게임 DLL과 빌드 출력 해시가 일치한다.
