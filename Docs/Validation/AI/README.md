# AI 대전 검증 기록

Unity 6000.0.74f1, Windows, 2026-11-08.

## 완료한 검사

- 순수 C# 규칙: 180개 통과, 실패 0 (`Rules.txt`).
- AI 대 AI: 3난이도 × 5맵 × 3시드 = 45경기 모두 종료. 최종 실행 4,722개 행동, 약 1.7초. 소환·공격·효과 대상·조합·도박·버리기·턴 종료를 모두 실행했다. 마나, 손패, ID 중복과 카드 수 보존을 검사했다.
- 실제 AI UI: 43개 통과, 실패/예외 0. 실제 타이틀 경로, EASY/NORMAL/HARD의 AI 턴, 고정된 사람 시점, 상대 카드 뒷면, 실제 포인터 턴 종료, 실제 AI 치명타 결과, 맵 재추첨/재대전 초기화, 계산 후 타임아웃 재검사를 포함한다. 최종 중요 카드 보존 수정 후에도 재실행했다.
- 튜토리얼: 34개 통과, 실패/예외 0. 실제 Raycast/포인터로 버리기 버튼과 손패 클릭도 검사한다.
- 기존 UI/상태 회귀: 451개 통과, 실패/예외 0 (공격 43, 드래그 58, PvP 화면 22, 조커 사건 107, 문양 맵 50, 포커 134, 손패/설정 37).
- 활성 프로젝트의 실제 Bee 참조와 Unity Roslyn으로 런타임 및 Editor 어셈블리를 별도 임시 경로에 컴파일했다. 모두 종료 코드 0, 오류 출력 없음. 기존 Editor 캐시는 덮어쓰지 않았다.
- 검증 프로젝트는 별도 Library 캐시를 사용했다. `SourceManifest.json`으로 Assets/UNKNOWN C# 소스가 작업 프로젝트와 동일한지 확인했다.

## 구현 중 발견하고 보완한 내용

- 일반 로컬 핫시트 시점을 그대로 쓰면 AI 턴에 AI 손패가 노출될 수 있어, AI 모드는 ViewPlayer를 사람 0으로 고정했다. 핫시트 넘김 화면도 AI 모드에서 사용하지 않는다.
- 실전 엔진을 그대로 복사해 탐색하지 않고, recipient 필터된 관측과 가상 덱 사전 분포로 시뮬레이션한다. 상대 비공개 손패/덱 순서/승리 카운터와 실전 난수를 탐색에 사용하지 않는 회귀 검사를 추가했다.
- AI 계산 직후 다시 시계를 확인하여, 계산 중 턴 시간이 만료됐으면 새 행동을 실행하지 않고 기존 만료 경로로 넘긴다.
- EASY에서도 불리한 버리기 후보는 제외하고, 모든 난이도에서 UNKNOWN 재료와 다음 턴 승리용 JOKER를 보존하는 조건을 검사했다.

## 증거와 한계

`ChecksSummary.json`과 개별 JSON이 원본 결과다. PNG는 1920×1080 전투 화면 및 1280×720 결과 화면의 실제 Unity 렌더다. AI UI의 승패 검사는 치명타가 가능한 고정 상태에서 실제 AI 선택과 실제 공격 명령을 실행한다. 자연스럽게 처음부터 끝까지 진행하는 45경기는 UI 없는 규칙 실행기에서 검증했다.

실제 다른 PC 사이의 네트워크 연결, 네트워크 어댑터를 물리적으로 끈 상태, 사람이 여러 경기 플레이한 난이도 체감/승률, 다른 GPU/OS에서의 성능은 검증하지 않았다. HARD는 제한된 휴리스틱/가상 탐색이며 최적 수를 보장하지 않는다. 일반 Player 실행에서는 개발 로그와 강제 테스트 상태가 활성화되지 않는다.

Windows 빌드와 최종 두 프로세스 Relay 결과는 `BuildSummary.json`, `RelaySummary.json`에 기록한다. 이전 정책 빌드의 Relay 17턴 성공 원본도 별도 before-policy 파일로 구분했다.

## 최종 Windows 및 Relay 결과

`Builds/UNKNOWN-AI/UNKNOWN.exe`의 Development Build 성공: 오류 0, 기존 경고 8. 최종 DLL 해시는 BuildSummary와 RelaySummary에서 일치한다. 같은 PC에서 이 빌드 두 프로세스를 실행해 서로 다른 Authentication Player ID, 동일 Project ID, Session Code 참가 및 Netcode 연결을 확인했다. 17턴 경기 종료 후 양쪽 결과·공개 상태·화면 샘플(Host 86, Guest 63) 일치, 각 수동 버리기 2회, 초과 드로우 폐기 5회, 중복 버리기 거부, 대기실 복귀, 세션 해제까지 통과했다. 양쪽 Error/Exception 0. 테스트 프로세스는 세션 해제 확인 후 종료했다.

다른 PC 간 접속은 이번 작업에서 재검증하지 않았다. Unity에 기존 Play가 켜져 있다면 종료하고 Assets > Refresh 후 SampleScene에서 다시 시작한다. 빌드는 실행 파일 하나가 아닌 UNKNOWN-AI 폴더 전체를 사용한다.
