# HARD 판단 강화 검증

2026-11-08, Unity 6000.0.74f1, Windows.

## 변경

기존 HARD는 자기 행동 두 번의 이득을 비교했고, 상대 턴의 실제 공격은 실행하지 않았다. 이번에는 시작 후보 최대 12개에서 자기 행동 최대 4번과 상대 공개 필드 공격 최대 5번을 비교한다. 단계별 후보 3개, 기본 384노드로 제한한다. `AiSearchSettings` 생성자에서 범위 내 설정을 변경할 수 있다.

상대 필드에 공격력이 있어도 자신의 방어 유닛이 남아 있으면 곧바로 플레이어 직접 피해가 발생하는 것으로 평가하지 않도록 수정했다. 상대에게 넘긴 턴의 가상 드로우 수 때문에 턴 종료 후보만 불리하게 평가되는 문제도 탐색 구현 과정에서 수정했다. 불리한 공격을 생략하는 상대 대응도 허용한다.

비공개 손패·덱 순서·승리 카운터·실전 난수 접근 제한을 유지한다. 새로 가상 드로우한 카드의 정체는 자기 연속 행동에 사용하지 않는다. 상대는 공개 필드로 공격만 하며, 미지의 손패로 소환할 카드를 확정하지 않는다. JOKER는 성공/실패 분기의 기대값을 비교한다. 매 실제 행동 이후 다시 계획한다.

## 실제 검사

- `Rules.txt`: 184개 통과, 실패 0. 기존 180개와 공격 순서/반격 방어/설정 제한/좌석 교대 표본 대전을 포함한다.
- 방해 유닛을 작은 공격력으로 제거하고 남은 두 공격으로 승리하는 3행동 순서를 검사했다.
- 큰 유닛과의 유리해 보이는 교환이 다음 턴 직접 공격 패배로 이어지는 경우, 작은 상대 유닛을 먼저 제거해 생존하는 선택을 검사했다.
- 실전 상태/난수 불변, 가려진 손패 및 비공개 카운터 교체 후 동일 선택, 도박 분기, 중요한 조합 재료 보존 회귀 검사를 유지했다.
- 5맵 × 2시드 × HARD 좌석 교대 = 20경기: HARD 17승, NORMAL 3승, 미종료 0. HARD 결정 1,094회, 이번 실행의 최대 결정 시간 46.69ms. 기기와 부하에 따라 달라진다.
- 3난이도 × 5맵 × 3시드 = 45경기 모두 종료, 총 4,865행동. 불법 행동, 손패 제한, 마나, 카드 ID/수 보존 검사를 통과했다.
- `UNKNOWN-AI-Checks.json`: 실제 Unity PlayMode UI 검사 43개 통과, 실패/예외 0. 타이틀 진입, 난이도별 AI 행동, 숨김 손패, 사람에게 턴 복귀, 실제 승패, 재대전, 타임아웃을 포함한다.
- 작업 프로젝트의 실제 패키지 참조를 사용한 런타임/Editor Roslyn 컴파일도 종료 코드 0이었다. 검사용 DLL은 Library의 별도 경로에 생성했다.
- `SourceManifest.json`: 검증 프로젝트와 작업 프로젝트의 AI 런타임 소스 SHA256이 일치한다.
- Windows Development Build 성공: 오류 0, 경고 8. `Builds/UNKNOWN-AI-Hard/UNKNOWN.exe`와 폴더 전체를 사용한다. `BuildSummary.json`에 DLL 해시를 기록했고 검증 프로젝트 출력과 복사본의 일치를 확인했다. 이전 `Builds/UNKNOWN-AI`는 유지했다.

첫 빌드 시도는 UI 검사 프로세스가 종료되기 전에 실행하여 Unity 프로젝트 중복 실행 오류로 중단됐다. 검사 프로세스 종료와 잠금 해제 후 재실행한 `Library/HardAI-Build-Retry.log`에서 빌드 성공 및 종료 코드 0을 확인했다. 빌드한 Windows 실행 파일에서 사람이 직접 AI 대전한 결과는 이번에 검증하지 않았다.

## 한계

17/20은 정해진 시드의 NORMAL 상대 표본이며, 이전 HARD 대비 승률이나 사람 상대 승률을 뜻하지 않는다. 사람의 플레이 습관을 학습하는 기능은 추가하지 않았다. 상대 손패 소환, 모든 확률 사건, 모든 가능한 행동 순서를 완전 탐색하지 않으므로 최적 수를 보장하지 않는다. 100ms 중단 검사는 시뮬레이션 사이의 비상 안전 장치이며 전체 호출 시간의 엄밀한 상한이 아니다.

이번 변경은 AI 정책 파일에 한정된다. 온라인 Relay 두 프로세스 접속, 다른 PC 접속, 튜토리얼/UI 전체 회귀 451개, 다른 기기의 성능, 사람이 느끼는 난이도는 이번에 재검증하지 않았다. 기존 AI 개발 당시 검사 기록은 `../AI`에 별도로 보존한다.
