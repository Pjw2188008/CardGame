# UNKNOWN 싱글플레이 Chapter 1

## 실행

기존 타이틀의 **싱글플레이 → 새로운 런**으로 진입한다. 기존 씬에서 별도 오브젝트·컴포넌트를 추가할 필요가 없다. AI 대전, 튜토리얼, 온라인 대전 메뉴도 유지한다.

해금된 난이도를 선택하면 기존 기본 덱(균형 12장)이 자동 적용된다. 시작 덱 선택과 시작 덱 해금 UI는 숨기며 기존 데이터·해금 내역·저장된 런 덱은 보존한다. 경로 화면의 밝은 노드를 선택한 뒤 **진입**을 누른다. 준비 화면에서 적·턴·마나·제약을 확인하고 전투를 시작한다. 전투 도중 메뉴에서 나가도 싱글 메인 화면의 **이어하기**로 복귀할 수 있다.

## 구현 범위

- 시작 1 / 일반전 11 / 엘리트 4 / 증강 3 / 회복 2 / 덱 정리 2 / 이벤트 1 / 보스 1, 총 25개 노드.
- 10개 계층의 무순환 경로. 모든 노드는 시작과 보스로 연결되며, 초기 두 전투 계층에는 약한 일반전을 배치한다. 시드 재현 및 최고 HP 보상 기준 보스 도달 가능한 토큰 경로를 검사한다.
- 런 토큰 10에서 시작. 진입 시 한 번 차감하고, 승리 확정 후 남은 HP 비율로 1~5 지급한다. 보상 선택 후 지불 가능한 다음 노드가 없을 때 실패한다. 보스 승리는 토큰 고갈보다 우선한다.
- 기본 런 덱 12장, 시작 손패 5장, 턴 시작 2장, 손패 8장. 빈 손패의 다음 턴에는 기존 방식의 5장 보충을 사용한다.
- 첫 일반전에서는 원래 시작 덱의 두 장을 **해당 전투에서만** A·J로 대체하고 시작 손패 5장에 확정 포함한다. 런 덱의 영구 구성과 카드 수는 바뀌지 않는다.
- 일반 카드·JOKER는 덱 소진 시 버린 더미에서 재셔플한다. 필드의 카드는 포함하지 않는다. 생성된 UNKNOWN은 재셔플 대상에서 제외한다. 조합 재료 A·J/Q/K는 버린 더미에 남는다.
- 제한 턴은 플레이어 턴과 적 턴을 묶은 라운드 기준이다. 싱글에는 실시간 40초 제한을 적용하지 않는다. 실제로 지불한 마나만 총 예산과 턴 지출에 반영하며 회복·반환은 예산을 복구하지 않는다.
- 적은 스테이지 카드 풀에서 매 턴 일반 적 1장, 엘리트·보스는 지정 라운드 또는 HP 조건 충족 시 최대 2장 소환을 시도한다. 초기 배치, 턴·HP·지정 카드 사망·UNKNOWN 소환 패턴도 유지한다. 초기 배치는 출전 효과를 발동시키지 않고, 패턴으로 새로 소환한 카드는 기존 출전 효과를 사용한다. 진행 중인 플레이어 효과를 덮어쓰지 않는다. 적 공격은 가장 낮은 HP의 아군 유닛을 우선하고, 필드가 비면 플레이어를 공격한다.
- 15개 제약 종류 및 강화/복합 난이도. 지정 슬롯 봉인은 해당 슬롯의 지속형 포커 보너스를 차단한다. 기존 카드의 일회성 출전 강화와 구분한다. 전투 종료 자동 회복은 없으며 HP가 다음 노드로 이어진다.
- 증강 12종과 최대 3슬롯 교체, 카드 3택1/건너뛰기, 카드 제거/교체, HP 회복, HP·토큰 거래 이벤트.
- 스페이드 카드 약화는 사용자 결정에 따라 **싱글에서만 기본 1라운드**, 증강의 첫 약화 효과는 2라운드다. 양쪽 스페이드 카드에 적용하며, 멀티의 영구 약화는 유지한다.
- 기존 UNKNOWN·JOKER·포커 효과를 재사용한다. 싱글 승리는 적 HP 0이며 UNKNOWN 3장/조커 3성공 승리를 적용하지 않는다.
- 챕터 클리어 영구 토큰, 최초 보너스 20, 일반/어려움/악몽/UNKNOWN 난이도 구매, 카드 풀 해금과 기록(시작 덱 해금 UI는 현재 비활성화). 유료 결제나 미출시 챕터는 추가하지 않았다.

## 데이터와 저장

`Assets/UNKNOWN/Battle/Resources/SingleChapter1.json`에서 노드, 비용, 적/패턴, 턴·마나 한도, 제약 수치, 증강 수치, 난이도, 시작 덱, 보상·해금 비용을 수정한다. 카드 ID는 기존 `CardDatabase` ID를 사용한다. 설명 문구도 수치에 맞춰 함께 편집한다. JSON enum 값은 `SingleChapter.cs`, `BattleEngine.Single.cs`의 선언을 따른다.

영구 진행도와 런은 `Application.persistentDataPath/unknown-chapter1-v1.json` 하나에 원자적으로 저장한다. 현재 Windows 프로젝트 설정 기준 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/RealCardGame/unknown-chapter1-v1.json`이다. Unity Authentication과 무관한 로컬 프로필이며 다른 PC와 자동 동기화하지 않는다.

노드·토큰·보상 상태 외에 전투의 손패/필드/덱/버린 더미, 선택 중인 효과, 소모 예산, 증강·패턴 발동 상태, 난수 진행을 저장한다. 전투 명령과 턴 전환 후 저장하며, 승리 직후 종료해도 재개 시 미정산 보상을 한 번만 처리한다. 지원하지 않는 저장 버전이나 잘못된 데이터는 오류를 표시하고 기존 파일을 초기화하지 않는다.

## 1차 플레이테스트 피드백 반영 — 2026-11-16

- 시작 덱 선택을 제거하고 기존 기본 덱을 자동 지급한다. 카드 보상·덱 정리·기존 저장은 유지한다.
- 지도에는 노드 종류·비용·현재/이동 가능 상태만 표시하고, 클릭한 노드의 상세 패널에서 제약과 보상을 확인한다. 연결선은 캔버스 크기에 맞춰 갱신한다.
- 메인 화면의 기능을 정리하고, 노드·보상·난이도·전투 준비 상세는 호버 툴팁을 제공한다. 전투 보조 정보는 **전투 정보** 버튼으로 펼치며 긴 예고는 마우스 휠로 스크롤한다.
- 스테이지의 `enemyPool`은 card/priority/minTurn/maxTurn/weight/condition/preferredSlot/maxUses로 조절한다. maxTurn/maxUses의 0은 무제한이다. 조건은 빈 문자열, half(적 HP 50% 이하), empty(적 필드 비어 있음), ally(적 아군 존재), pattern(고정 패턴 전용)이다. 등장 턴은 글로벌 턴이 아닌 라운드다.
- 적 소환 설정은 `enemyStartMana`, `enemyManaRecovery`, `enemyManaCap`, `enemyBudget`, `enemySummonsPerTurn`, `enemyExtraTurn`, `enemyExtraHP`다. 카드의 실제 비용을 지불하고 턴당 수량과 누적 예산을 검사한다. 기존 마나 회복 카드도 적 소환 자원에 반영한다. 고정 패턴 소환도 같은 수량·비용 제한에 포함한다.
- 필드 포화·자원 부족·조건 미충족 시 강제 소환하지 않는다. 소환된 카드는 기존 출전 효과와 소환 턴 공격 제한을 적용한다. 소환 수량·예산·카드 사용 횟수·난수 진행은 전투 저장에 포함한다.
- 카드 카탈로그·온라인 코드·기존 전투 엔진 공통부·플레이어 규칙은 이번 피드백에서 수정하지 않았다. 적 HP·제한 턴·플레이어 마나 예산도 유지하고 적 전용 소환 예산으로 압박량을 제한했다. 난이도 균형은 추가 사람 플레이가 필요하다.

지도는 좌측의 **가로 스크롤/드래그 경로**와 우측의 **고정 상세 패널**로 구성한다. 하단 스크롤바로도 전체 25개 노드를 볼 수 있다. 노드는 종류, ◷ 제한 턴, ◆ 진입 토큰, 상태를 표시한다. 비전투 노드에는 전투 턴 제한을 표시하지 않는다. 상세 패널은 적 HP·제한 턴·총 마나 예산·진입 토큰·실제 난이도를 반영한 방해 효과·보상을 보여준다.

현재 위치는 황금색, 이동 가능 노드는 청록색, 토큰 부족은 붉은색이다. 완료와 선택하지 않은 이전 분기를 구분한다. 노드 클릭은 상세 확인이며 **진입** 버튼으로 이동한다. 이동 불가 사유와 부족 토큰 수를 표시하고 진입 버튼을 비활성화한다. 지도에는 런 토큰만, 메인/해금 화면에는 영구 토큰을 표시한다.

## 스테이지 제한 턴·전투 난이도 개편 — 2026-11-16

원인: 일반전 11개가 모두 `turnLimit=10`, 엘리트 11, 보스 14였으며 UI와 엔진에서 기본값으로 덮어쓰지는 않았다. 이번에는 실제 생성된 노드 레이어와 전투 유형으로 제한을 계산한다. 지도/준비 화면의 `SingleCampaign.TurnLimitFor`와 실제 전투의 `SingleBattleSession.Limit`이 모두 `SingleStage.ResolveTurnLimit`을 사용한다. 전투 진입 시 노드의 `layer`를 전달하며, 저장한 노드 레이어도 재사용한다.

일반 난이도의 적용 범위(사용자 표기 Layer 1~10, 내부 인덱스 0~9):

| 배치 | 일반 전투 | 엘리트 | 보스 |
| --- | --- | --- | --- |
| Layer 1~3 | 5~6 | 6 | — |
| Layer 4~6 | 4~6 | 5~6 | — |
| Layer 7~9 | 3~5 | 4~5 | — |
| Layer 10 | — | — | 8 |

비전투 노드는 제한 0이며 전투 제한을 표시하거나 적용하지 않는다. 1턴은 플레이어와 적의 턴을 묶은 기존 라운드 단위를 유지한다. 마지막 허용 라운드 승리는 유효하다. 초과 라운드는 드로우/마나/포커 턴 시작 효과 **이전**에 패배 처리하며 저장 복원 시에도 확인한다. 진행 중 저장을 새 버전으로 재개할 때 이미 새 제한을 넘겼다면 TURN LIMIT로 종료한다. 저장 데이터 초기화나 카드 규칙 변경은 없다.

편집 항목은 `SingleChapter1.json`에 있다:

- `battleType`: Normal=0, Rush=1, Bulwark=2, ManaLimited=3, CardLimited=4, Elite=5, Boss=6.
- `turnLimit`: 전투 유형의 기본값. 속공 3, 일반/마나 제한 5, 방어 돌파 6, 카드 제한 5~6, 엘리트 6, 보스 8. 실제 노드가 전달되면 일반/엘리트는 `layerTurnLimits=[초반,중반,후반]`을 사용한다. 보스는 `turnLimit`을 사용한다.
- `minimumTurns`: 난이도 보정 후에도 보장할 최솟값. 모든 전투 3 이상, 방어/복합 카드 제한은 주로 5, 보스는 7로 보호한다.
- 난이도의 `turnAdjustments`: `{minLayer,maxLayer,reduction,types}`. Layer 번호는 1부터 시작하며 중복 규칙은 최댓값만 적용한다. 어려움은 일부 일반/속공/마나 제한 중후반에 1 감소, 악몽은 중후반 및 후기 카드 제한/엘리트에 1 감소 규칙, UNKNOWN은 일부 후기 2 감소와 보스 1 감소 규칙이다. 최솟값에 걸리면 줄이지 않는다. 기존 `turnPenalty`는 호환 필드로 0을 보존하며 새 계산에서 사용하지 않는다.

짧은 제한에 맞춰 싱글 스테이지의 적 HP·초기 배치·마나 제한전 예산을 조정했다. 초반/속공에 낮은 적 HP와 1유닛 배치를 두고, 방어 돌파는 하트 유닛과 5턴 이상의 하한을 유지했다. 마나 제한전 총 예산은 18이다. 엘리트0/1과 보스의 추가 2장 소환은 늦은 턴/적 HP 25% 이하로 조정했다. 엘리트0은 반복 광역 피해로 필드를 봉쇄하지 않도록 풀의 Diamond_4/7을 각각 1회로 제한했다. 적의 기본 매 턴 1장 소환과 기존 소환 턴 공격 제한은 유지한다. 보스는 UNKNOWN 초기 유닛과 조건별 패턴을 유지하며 초기 회복 유닛을 제거했다. 고정 턴 패턴도 짧은 기본 제한 안에 오도록 앞당겼다.

카드 52종/UNKNOWN/JOKER 효과·비용, 맵 방해 효과 종류·수치, 증강, 포커, 런/영구 토큰, AI 로직, 온라인 코드는 수정하지 않았다. 공통 `BattleEngine.BeginTurn`에는 싱글일 때만 실행되는 초과 턴 검사 1줄을 추가했다. UI는 유형명과 실제 제한 표시만 연결하고 디자인을 유지했다.

최종 검증은 `Library/UNKNOWN-Systems-BuildProject/Library/TurnLimitChecks/`에 있다. `turn-limits.json`에 100개 시드의 실제 레이어 분포/최소 턴/난이도/경계 판정 4,399항목과 일반 난이도 31개 전투 결과를 기록했다. 31건 모두 정상 종료, 28승/3패였다. 최종 진행 덱(기본 12장 + A/J/다이아7/스페이드Q) 9표본은 `audit.json`에 최신 데이터끼리 합쳤고, 조정한 엘리트0/1 및 보스 모두 제한 내 승리 사례가 있었다. 모든 시드에서 승리한 것은 아니다. 과거 튜닝 표본 파일은 이전 수치의 결과도 포함하므로 최종 비교에는 `audit.json`을 사용한다.
