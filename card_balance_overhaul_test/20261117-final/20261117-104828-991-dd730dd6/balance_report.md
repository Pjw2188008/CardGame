## A. 실제 수정 결과

실제 기본 `FullBalanceRework` 카드 정의 52장을 첨부 명세의 마나·공격력·체력·설명·효과로 교체했다. 별도 프리셋, 테스트 프로젝트, 씬, 게임 모드는 만들지 않았다.
보호(최댓값 유지·다음 피해에 소모), 최대 3 약화와 대상 다음 턴 종료 복구, 공격/처치/소유자 턴 시작 효과, 임시 공격력, 성장 2회 제한, 카드 추가 마나 턴당 +2, 다음 배치 할인(최저 1), 선택 버리기를 기존 엔진과 UI에 연결했다.
기존 싱글 약화 추적기와의 중복 복구, 할인 전 예산 검사, 재순환 시 새 상태 초기화도 카드 효과 호환 범위에서 수정했다. 기존 싱글 약화 증강의 기간 연장은 유지했다.
현재 프로젝트 Unity 6000.0.74f1에서 런타임·에디터 컴파일 후 검증 97개를 통과했다. 최종 소스와 같은 기본 카드 데이터/전투 엔진으로 아래 AI 대전을 실제 실행했다.

## E. 문제와 해석

- 전투 길이: 전체 평균 24.68글로벌 턴. 참고 목표 16~24턴과 비교하되 실제 플레이 시간은 측정하지 않았다.
- 선후공: 선공 52.83%. 맵당 100판만으로 작은 차이를 확정하지 않는다.
- UNKNOWN 필드 3장 승리: 0회(0.00%). 목표 5%와 비교할 필요가 있다. 조합 재료 비용과 AI의 사용 선택이 함께 영향을 주므로 카드 수치만의 문제로 단정하지 않는다.
- 관측 사용 승률 상위(100회 이상 사용): Heart_Q 57.94% / 359회, Diamond_J 55.61% / 401회, Heart_K 55.56% / 423회, Club_J 55.30% / 443회, Club_K 55.05% / 376회.
- 관측 사용 승률 하위(100회 이상 사용): Diamond_2 42.06% / 466회, Spade_7 41.47% / 434회, Diamond_4 41.39% / 476회, Spade_4 40.37% / 488회, Club_8 39.89% / 371회.
- 카드 승률은 그 카드를 사용한 플레이어-경기의 관측값이다. 손패/보드/다른 카드/AI 정책에 따른 선택 편향이 있으므로 강약 확정이나 자동 수치 보정에 쓰지 않았다.
- 무한 반복/교착: 아래 미종료 기록을 참조한다. 종료되지 않은 경기를 제외한 승률만 제시하고 발생 건수는 별도로 공개했다.
- AI 한계: 기존 전략의 새 효과 분기 인식만 확장했다. 할인·공격 추가 피해·보호를 장기적으로 최적으로 계획하는지, 실전 전략 다양성과 동일한지는 추가 검증이 필요하다.
- 포커: 활성화와 기존 페어 구성원 판정을 검증했다. 족보별 실제 발생 빈도 및 별도 관측 승률은 기존 수집기가 보관하지 않아 미측정이다.
- 비용 할인으로 절약한 마나, 카드별 보호 부여 횟수, 전략 의도, 강화의 인과적 추가 피해는 별도 정밀 지표가 없어 미측정이다. 기존 buffExtraDamage/debuffPreventedDamage는 추정 귀속량이며 확정 기여로 사용하지 않았다.
- 기존 선택 UI를 재사용했다. 클로버 4/9는 남은 손패가 있을 때 1장 선택을 요구하며 없으면 해당 교환 효과를 생략한다. 클로버 Q는 0~2장을 선택하고 선택 수+2장을 드로우한다. 화면 디자인과 애니메이션은 변경하지 않았다.
