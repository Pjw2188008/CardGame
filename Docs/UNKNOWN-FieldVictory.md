# UNKNOWN 필드 승리 규칙

일반 전장과 문양 전장에서 **자기 필드에 살아 있는 UNKNOWN 3장이 동시에 존재**해야 UNKNOWN 승리가 발생한다. 손패, 덱, 버린 카드, 파괴된 카드는 승리 스택에 포함하지 않는다. 세 번째 UNKNOWN의 소환 효과를 모두 처리한 뒤 생존 수를 확인한다. 상대 HP 0 승리와 조커의 유희의 JOKER 3회 성공 승리는 유지한다. 조커 맵에서는 UNKNOWN 3장이 필드에 있어도 승리하지 않는다.

`PlayerState.UnknownProgress`는 살아 있는 필드 UNKNOWN 수를 계산한다. 파괴 경로마다 별도 카운터를 감소시키지 않으므로 전투, 소환 능력, 도박 실패, 족보 해제에 따른 파괴도 동일하게 반영된다. UI의 3칸 진행도와 AI의 승리 판단도 이 값을 사용한다.

`UnknownCreated`는 카드 수 보존/생성 이력용 누적 값으로 남겨두며 승리를 판정하지 않는다. 조합 제한은 현재 손패와 필드의 `UnknownHeld`를 기준으로 한다. 기본 최대 보유는 3장이고 파괴·버리기로 빈 만큼 재조합할 수 있다. 손패에서 필드로 옮기는 것은 보유 수를 늘리지 않는다.

Host의 BattleEngine이 승리를 판정하며 Snapshot의 승자·사유·필드와 본인의 `unknownProgress`를 Client에 전달한다. 상대의 진행도 필드는 기존과 같이 가린다. 온라인 양쪽은 같은 수정 버전을 사용해야 한다.

튜토리얼 7단계도 J/Q/K 조합 후 세 장을 직접 필드에 드래그해야 완료한다. 턴을 넘길 수 없는 실습 시나리오에서는 소환 후 마나를 10으로 재충전하며 안내 문구에 명시한다. 일반/AI/온라인 경기의 마나 규칙은 바꾸지 않는다.

검사 명령: `Tests/UNKNOWN/Run-BattleTests.ps1`. 추가 검사는 손패 3장으로 승리하지 않음, 필드 세 번째 소환 승리, 소환 효과 대기 중 미종료, 효과 완료 전 파괴 시 미승리, 전투/도박 파괴의 스택 제거 및 재조합, 조커 맵 예외, Snapshot의 본인 진행도와 상대 마스킹을 포함한다.

Windows 최신 규칙 빌드: `Builds/UNKNOWN-FieldVictory/UNKNOWN.exe`. 실행 파일만 분리하지 않고 폴더 전체를 사용한다. 이전 AI/HARD 빌드는 이전 승리 규칙이므로 온라인 양쪽 모두 새 빌드로 맞춘다. 실제 검사 결과와 미검증 항목은 `Validation/UNKNOWN-FieldVictory`에 기록했다.
