# 마나·턴 제한·전투 연출 통합

## 실행과 설정

기존 `Assets/Scenes/UNKNOWN_Battle_Test.unity`를 열고 Play. Canvas와 이펙트 레이어가 코드로 생성된다. 추가 에셋이나 패키지 설치, Inspector 연결은 필요 없다. 기존 카드 공격력/체력/효과, 조합 제한, 조커 확률은 유지했다.

`UNKNOWN Battle Prototype > Battle UI Controller`에서 `Turn Duration`을 변경할 수 있다. 기본 60초다. 짧게 시험하려면 5~10초로 바꾼다. Play 중 바꾸면 다음 턴부터 적용된다. `Seed`와 `Reveal Hands`도 기존대로 사용할 수 있다.

## 마나

- 각 플레이어의 첫 자기 턴: 3/3 MP. 두 번째부터 4/4, 5/5… 최대 10/10.
- 자기 턴 시작에만 최대 마나가 증가하고 현재 마나가 최대치로 회복된다. 남은 마나는 더해서 이월하지 않는다.
- 턴당 1회 소환 제한은 제거했다. 마나와 빈 슬롯이 있으면 같은 턴에 여러 유닛을 소환한다.
- 비용: 2/3=1, 4/5=2, 6/7=3, 8/9=4, 10=5, J=6, Q/A=7, K=8.
- UNKNOWN 조합은 0 MP. UNKNOWN J/Q/K 소환은 7/8/9 MP. 조커는 유효한 사용을 확정할 때 2 MP.
- 부족/잘못된 대상/가득 찬 슬롯에는 마나·카드를 소모하지 않는다. 조커 확률도 굴리지 않는다.
- 정보 영역의 숫자와 10칸 게이지: 파랑=사용 가능, 짙은 파랑=사용함, 회색=미해금. 사용 시 해당 칸에 빛이 사라지는 효과를 표시한다.
- 카드 좌측 상단에 비용을 표시하고 부족한 패는 어둡게 표시한다. 카드를 선택하여 조합 재료로 쓰는 것은 마나와 무관하게 가능하다.

## 턴 시간과 입력

중앙 상단 숫자와 게이지가 실제 경과 시간을 표시한다. 10초 이하 빨강, 5초 이하 깜빡임, 0초 TIME OUT. 턴 시작 문구는 P1 기준 YOUR TURN/P2 기준 OPPONENT TURN이고, 실제 핫시트 조작자는 화면 아래 플레이어다.

`일시정지` 버튼 또는 외부 `Time.timeScale = 0`에서 시간과 연출을 멈춘다. 앱 일시정지 중에도 멈춘다. `계속하기`로 게임 내 일시정지를 해제한다. 핫시트 화면을 넘기는 시간과 턴 전환 배너는 행동 시간을 소비하지 않는다. 준비 완료와 시작 연출 후 온전한 턴 시간이 주어진다.

행동 애니메이션 중에는 시간이 흐르지만 추가 카드 조작·조합·조커·턴 종료를 차단한다. 시간 초과 시:

1. 새 입력을 차단한다.
2. 이미 확정된 소환의 미선택 효과 대상은 유효한 슬롯 순서로 자동 선택하여 완료한다. 연쇄 피해는 서로 다른 적을 선택한다.
3. 진행 중인 연출과 시간 초과로 생긴 나머지 결과 연출을 마친다.
4. 한 번만 턴을 전환한다. 핫시트라면 다음 사람의 준비 화면을 표시한다.

사용자가 효과 대상 선택을 계속 미뤄 무한 턴이 되는 것을 방지한다. 종료 버튼을 연타해도 턴을 중복 전환하지 않는다. 승패가 확정되면 타이머를 중지하고 연출 완료 후 승리 화면을 표시한다.

시작 패는 5장씩 한 번만 지급하고, 첫 턴 시작 드로우는 별도로 1장이다. 따라서 첫 플레이어 최초 패 6장 규칙은 유지한다.

## 연출

모든 수치는 BattleEngine에서 먼저 확정하고, CardAnimationController는 불변 BattleEvent를 순서대로 재생한다. 이벤트에는 카드 객체 대신 ID, 대상, 실제 적용 변화량 등이 들어 있어 유닛 파괴 후에도 안전하게 연출할 수 있다. 애니메이션은 피해 계산이나 확률 판정을 재실행하지 않는다.

| 동작 | 연출 |
| --- | --- |
| 소환 | 선택 가능한 빈 슬롯 강조, 패 카드의 분신이 필드로 이동·확대, 문양색 소환파 |
| 공격 | 1.1배 확대 → 대상 돌진 → 충격파·흔들림·양쪽 실제 피해 숫자 → 복귀, 약 0.5초 |
| 피해/회복/강화 | 실제 적용량의 위로 떠오르는 숫자, 색상 점멸. 카드별 숫자 위치를 나눠 겹침 완화 |
| ♦ | 붉은 빛의 이동·충격파, 피해에 따른 충격파 크기, 연쇄는 이전 적 위치에서 다음 적으로 이동 |
| ♠ | 보라색 약화·아래 화살표, 상대 패 순차 축소·소멸 |
| ♥ | 분홍색 공격 빛, 초록 회복·확산, 피해 대상에서 자신으로 돌아오는 빛 |
| ♣ | 공격력 위 화살표, 초록 체력 강화·확대, 덱 위치에서 패로 카드 이동 |
| 파괴 | 붉게 점멸·흔들림·축소·페이드, 카드당 약 0.4초 |
| UNKNOWN 조합 | 두 재료가 중앙으로 이동·겹쳐 축소, 보라색 빛, 결과 등장 후 패로 이동, 약 1초 |
| 조커 | 조커 이동·회전하는 빛 → 확정된 결과의 SUCCESS/FAILED → 강화 수치 또는 파괴 |
| 직접 공격 | 상대 체력 위치로 돌진·충격파·실제 피해, 복귀 후 체력 UI 갱신 |

UNKNOWN 카드는 어두운 배경과 보라색 테두리로 구분한다. 외부 이미지 없이 UI 도형과 코드에서 만든 작은 원형 광원을 사용한다. 카메라 이동이나 화면 전체 흔들림은 없다.

하트의 회복량은 기존 카드 데이터의 고정 회복량을 그대로 사용한다. 돌아오는 빛은 시각 표현이며 실제 피해량 기반 흡혈 규칙으로 바꾸지 않았다. 회복이 최대치에 막히면 +0, 공격력 감소가 0에 막히면 실제 감소량만 표시한다. 직접 공격의 과잉 피해도 남은 플레이어 HP까지만 숫자로 표시한다.

## 코드

- `CardData.cs`: 불변 카드 정의에 ManaCost 추가. 기존 능력치/효과는 유지.
- `BattleEngine.cs`: 플레이어 마나·자기 턴 횟수, 비용 검증/차감, 시간 초과 확정, 결과 이벤트 생성.
- `BattleEvents.cs`: 불변 연출 결과 데이터. 읽어서 비우는 DrainEvents로 중복 재생 방지.
- `TurnClock.cs`: Unity에 의존하지 않는 실제 시간 기반 타이머.
- `CardAnimationController.cs`: UI 복제본 이동, 도형 이펙트, 순차 연출, 숫자·파괴·조합·조커.
- `BattleUIController.cs`: 자원/시간 UI, 입력 잠금, 애니메이션 완료 후 UI 갱신과 턴 교대.
- `BattleUIController.PlayModeChecks.cs`: UNITY_EDITOR에서만 포함되는 실제 코루틴 통합 검증.

## 재검증

규칙 테스트: 프로젝트 루트에서 `cmd /c Tests\UNKNOWN\Run-BattleTests.cmd`. 58개 테스트는 기존 카드 데이터 전체 대조와 전투/조합/조커, 마나 비용/회복/상한/부족, 시간 경과·정지·재설정, 시간 초과 대상 자동 확정, 중복 턴 방지, 실제 변화량 이벤트를 검증한다.

실제 UI/코루틴 통합 검증: 전투 씬에서 Play 후 `UNKNOWN > Battle > Run Play Mode Integration Checks` 또는 Ctrl+Alt+T. 이 검증은 테스트 전용 고정 상태를 만들어 소환·공격·회복·드로우·버리기·연쇄·UNKNOWN·조커 양쪽 결과·직접 승리·애니메이션 중 시간 초과·중복 입력·일시정지를 순서대로 실행한다. 완료 후 일반 새 게임으로 복귀한다. 결과는 `Library/UNKNOWN-Battle-PlayMode.json`에 저장하고 Console에 요약한다. 테스트용 상태 생성은 일반 NewMatch에서 사용하지 않으며 빌드에도 포함되지 않는다.

기존 Multiplayer Services/Relay/Lobby 패키지·설정은 변경하지 않았다. 이번 기능은 로컬 핫시트 프로토타입이며 온라인 전투 동기화는 추가하지 않았다.

- Unity 6000.0.74f1에서 에디터/플레이어 코드 경로 컴파일 통과.
- 규칙 자동 테스트: **58 통과, 실패 0**.

- 수동 UI 관찰: 3/3 MP, 카드 비용과 부족 카드 어둡게 표시, 60초 자동 종료 후 핫시트 교대, 다음 턴 60초 시작, PAUSED 표시를 확인했다.
- 검증 환경은 현재 Windows Unity Editor다. 실제 독립 Windows 빌드 실행 및 다른 화면 비율/플랫폼 시각 검증은 별도로 수행하지 않았다.
