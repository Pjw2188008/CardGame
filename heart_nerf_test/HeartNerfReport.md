# UNKNOWN 하트 생존 성능 하향 비교

검증일 2026-11-11. 현재 기본 플레이 데이터에 HeartNerf를 연결했다. 기존 Revised 데이터는 별도 버전으로 보존했다. AI, 맵, 포커 및 공통 전투 효과 처리 로직은 기존 소스를 사용했다.

## 적용한 수치

|---|---|---|
|♥9|아군 전체 회복 3|아군 전체 회복 2|
|♥Q|아군 전체 최대·현재 HP +3, 회복 3|아군 전체 최대·현재 HP +2, 회복 2|

57종을 전수 비교해 위 효과의 수치 5개만 달라졌음을 검사했다. 카드 마나·공격력·기본 HP, 효과 종류·대상·순서·FreshTarget 조건과 나머지 카드 설명은 동일하다. 세 카드 설명의 숫자도 갱신했다. ♥Q의 최대 HP와 현재 HP 증가는 기존 IncreaseMaxHP 경로로 함께 +2 적용된다. ♥K의 첫 능동 공격 1회, 반격 후 생존, 최대 HP 상한, 무손상 시 소비 조건은 기존 처리 경로를 따른다.

## 실행 조건과 검사

HeartNerf 1,000판과 새 기준 Revised 1,000판을 실행했다. 이전 보관 결과의 Revised는 주 비교 480판과 스트레스 20판으로 총 500판이므로, 1,000판 전체의 공정한 대응을 위해 기준판을 추가 실행했다.

초기 500판은 기존의 주 비교 480판과 스트레스 20판을 동일한 순서로 재사용했다. 다음 500판은 같은 구성에 두 번째 고정 시드를 적용했다. 한 버전당 주 비교 960판은 6맵 각각 160판이며 선후공 교환으로 구성했다. Random 스트레스 40판에는 Random 대 Random과 다른 AI가 포함된다. Aggressive, Control, Effect, Random 정책은 수정하지 않았다. Seed는 첫 블록 7312026, 두 번째 블록 57312029다.

초기 덱·손패·맵·AI 정체성·선후공·덱 시드·정책 시드·전투 시드를 1,000쌍 모두 대조했다. 포커 시너지는 모든 실험에서 false다. 실제 플레이의 포커 설정은 기존값을 사용한다. 현재 마나·드로우·UNKNOWN·조커·멀티플레이 승패 규칙 변경은 없다.

고정 상황 및 기존 Revised 기능 검사 367개를 통과했다. 여기에는 전 카드 수치 대조, ♥Q의 손상 아군과 소환 본체의 최대·현재 HP 증가, ♥K의 생존 회복·두 번째 공격·반격 사망·무손상 소비 검사가 포함된다. 최종 격리 Unity 컴파일은 오류 0개로 통과했다. 최초 작성 중 검사 어셈블리 접근과 타입 충돌 컴파일 오류를 수정한 뒤 이 결과를 실행했다.

두 실행의 AI·맵·규칙 데이터·규칙 소스 해시가 같음을 검사했다. 기존 소스/설정 해시와 비교해 허용한 버전 조회·기본 버전 연결·기존 검사 버전 지정 외의 원본 파일은 변하지 않았다. 기존 Revised 500판의 결과와 RNG 이력을 재검사했을 때 불일치 0개였다.

전투 결과가 달라지면 난수 소비도 달라진다. 1,000쌍 중 735쌍의 전투 RNG 이력이 달랐다. 같은 초기 시드가 전투 전체 난수를 일대일 대응시키지는 않는다.

## 남은 한계와 후속 후보

이번 실험은 기존 AI 정책하의 관측 비교다. 사람의 실제 조작, 서로 다른 PC의 온라인 대전, 새 Windows 빌드의 플레이 검사는 실행하지 않았다. 이번 수정은 카드 수치와 버전 연결에 국한되며 이전 Windows EXE는 이번 수치가 들어간 빌드가 아니다. 일반 플레이는 Unity에서 현재 소스를 실행하면 HeartNerf를 사용한다.

전체 평균은 약 0.39%만 감소했고 공통 완료 대응 평균은 약 0.01턴 증가했다. 미종료와 동일 AI 선공 승률도 증가해 이번 변경을 전반적인 개선으로 판정하기 어렵다. 우선 세 카드를 한 번에 바꾼 영향을 분리하기 위해 ♥Q의 최대·현재 HP 증가 한 항목만 기존 수치로 되돌린 대응 실험 또는 ♥K의 자기 회복 한 항목만 되돌린 대응 실험을 각각 비교하는 것이 후속 후보이다. 이번 결과로 후보를 자동 적용하지 않았다. 고갈 교착 종료 규칙은 별도의 규칙 실험으로 검토해야 한다.

## 저장과 재실행

모든 원본 9개 통계 파일은 실행 폴더의 Revised와 HeartNerf 하위 폴더에 있다. comparison 폴더에 match_comparison.csv, heart_effect_comparison.csv, heart_usage_comparison.csv, suit_damage_comparison.csv, unknown_comparison.csv, paired_completed_games.csv, card_changes.csv 및 comparison.json을 저장했다. experiment.json에는 57종 전후 데이터, 전체 일정, 검사 통과 목록이 있다. baseline_backup에 변경 전 원본 소스와 해시를 보관했다.

상세 이벤트는 effect_events.jsonl.gz로도 저장했다. 텍스트 원본은 로컬 보관용 Git 제외 대상이다. 압축 복원 후 SHA-256 일치를 검사한다. 100MB 초과 원본이 다시 업로드되지 않도록 heart_nerf_test 경로에도 제외 규칙을 추가했다.

Unity 메뉴 Tools > UNKNOWN > Run Heart Nerf Comparison으로 새 결과 폴더에 동일 비교를 재실행할 수 있다. 이 메뉴는 Revised 1,000판을 먼저 실행한 뒤 HeartNerf 1,000판을 실행한다. 이미 실행 중일 때 다시 누르면 중복 실행을 차단한다.

수정 파일은 CardData.cs의 버전별 조회, BattleEngine.cs의 기본 버전 지정 한 줄, 기존 CardRedesignChecks.cs의 명시적 Revised 검사 지정이다. HeartNerfCardCatalog.cs, HeartNerfChecks.cs, HeartNerfBatch.cs를 추가했다. AI와 맵 소스는 수정하지 않았다.
