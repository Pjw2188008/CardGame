# 전투 드래그 UI

전투 화면의 우측 고정 패널을 제거했습니다. 기존 SampleScene 및 UNKNOWN_Battle_Test의 BattleUIController가 런타임에 새 Canvas를 생성하므로 Inspector 참조를 다시 연결할 필요가 없습니다. 기존 NetworkManager와 Relay 방 코드는 유지합니다.

## 조작

- 소환/공격: 기존 카드 선택 → 빈 아군 슬롯 / 적 카드 클릭 방식을 유지합니다. 상대 필드가 비면 상단의 상대 직접 공격 버튼이 활성화됩니다.
- JOKER: 손패의 조커를 아군 필드 카드에 드래그하고 놓으면 즉시 도박합니다. 별도 확인 버튼은 없습니다. 유효한 대상은 금색, 불가한 대상은 빨간색입니다. 일반 유닛과 UNKNOWN 모두 가능하며 기존 마나·중복 사용·턴·승패 검증을 그대로 거칩니다.
- UNKNOWN: 손패 A를 중앙 A 슬롯에, J/Q/K를 다른 중앙 슬롯에 드롭합니다. 등록만으로 재료는 소모되지 않습니다. 미리보기 확인 후 조합 버튼을 누르면 Host에 기존 조합 요청을 보냅니다. 슬롯 클릭은 개별 해제, 다른 재료 드롭은 교체, ESC는 전체 취소입니다. 턴 종료와 상태 갱신 시 선택을 초기화합니다.
- 상세 정보: 자기 손패나 공개 필드 카드를 가리키면 작은 툴팁이 나타납니다. 화면 가장자리에서는 위치를 안쪽으로 조정합니다. 상대 손패 뒷면에는 Hover/Drag 컴포넌트나 비공개 카드 정의를 붙이지 않습니다.
- 메뉴: 좌상단 작은 메뉴 버튼에서 메인 메뉴로 이동합니다. 로컬 일시정지/개발용 기능도 이 접힌 메뉴 안에 있습니다. 온라인에는 손패 공개 기능을 제공하지 않습니다.

## 구현

CardDrag는 Unity의 IBeginDragHandler/IDragHandler/IEndDragHandler를, CardDropZone은 IDropHandler와 PointerEnter/Exit를 사용합니다. 드래그 복제본은 별도 레이어에 생성하고 Raycast를 차단하지 않습니다. 원본의 위치·크기·손패 데이터는 이동하지 않으며 알파만 임시 변경합니다. 드롭 처리 전에 드래그 문맥을 해제하므로 중복 Drop/EndDrag가 같은 요청을 두 번 전송할 수 없습니다.

Client는 기존 BattleAction.Joker/Combine 요청만 보냅니다. RNG, 마나 차감, 재료 소모와 승리 판정은 기존 Host 엔진이 처리합니다. 거부된 요청은 원본 카드가 유지되고 짧은 안내로 표시됩니다.

5칸 보드는 같은 폭으로 중앙 정렬하고 최대 너비/높이를 제한했습니다. 손패는 실제 사용 가능 폭과 카드 수로 간격과 크기를 계산하며 마스크에 잘리지 않도록 구성했습니다. 1920×1080 CanvasScaler를 유지합니다. 전투 로그는 하단 구석의 최근 3개 항목으로 축소했습니다.

상대의 거대한 카드가 남는 문제는 비공개 드로우 이벤트들이 같은 익명 ID(-1)를 쓸 때 이전 FX 복제본 참조가 덮어써지는 경로였습니다. 익명 복제본 교체 시 이전 객체를 제거하고, 드로우 하나가 끝날 때마다 작은 뒷면 복제본을 즉시 정리하도록 수정했습니다.

## 검증 방법

`Tests/UNKNOWN/Run-BattleTests.cmd`로 기존 67개 규칙/프로토콜 검사를 실행합니다. Unity 메뉴 `UNKNOWN > Multiplayer > Run Drag UI Checks`는 실제 Unity UI 이벤트로 조커 유효/무효 드롭, 취소, 중복 드롭, 성공/실패, 재료 등록·교체·해제·확정, 툴팁과 익명 드로우 정리를 검사합니다. 보고서는 `Library/UNKNOWN-DragUI-Checks.json`입니다. 검사에 사용하는 카드 지급과 고정 주사위는 UNITY_EDITOR 전용 코드입니다.

Windows 빌드는 기존 `UNKNOWN > Multiplayer > Build Windows Test Player`를 사용합니다. 양쪽 PC에는 같은 최신 빌드 폴더 전체를 전달합니다.
