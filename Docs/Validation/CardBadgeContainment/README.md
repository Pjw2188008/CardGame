# 카드 하단 숫자 넘침 수정

2026-11-10, Unity 6000.0.74f1.

공격력·체력의 배치 중심이 원본 이미지의 배지보다 낮았으며, 조커 50% 영역도 카드 하단에 너무 가까웠다. 마나 영역은 유지하고 공격력·체력의 영역을 원본 배지 안쪽으로 올려 조정했다. 조커 50%는 설명 아래 별도 내부 영역으로 옮기고 글씨 크기를 줄였다. 조커 설명도 퍼센트 영역과 겹치지 않도록 조정했다.

CardBadgeCenter는 실제 보이는 글자의 중앙 정렬에 더해, 글자 메시가 텍스트 영역보다 크면 비율을 유지해 축소한다. CardArtLayout은 손패 크기 변경이 발생한 프레임의 LateUpdate에서 최종 배치를 한 번 더 갱신한다. 입력 영역과 마나 위치, 게임 수치/규칙, 원본 이미지는 변경하지 않는다.

첨부 화면과 같은 6장(Spade_2/Joker_2/Spade_Q/Heart_3/Diamond_6/Heart_Q) 손패를 재현했다. 각 카드의 숫자가 그림 안에 남는지 검사하고, 실제 CardHover 확대 및 8장으로 늘어나는 재배치 뒤에도 다시 검사했다. 1280×720과 1920×1080 캡처를 생성하고 1920 화면을 직접 확인했다.

UI 검사 741개 통과, 실패/예외 0: 카드/공격 296, 드래그 58, PvP 26, 조커 사건 107, 문양 맵/배경 80, 포커/수치 137, 손패/설정 37. 실제 Relay 연결과 튜토리얼 전체 실습, 모든 기기/비율은 이번에 재실행하지 않았다. 수정 전 파일은 현재 작업 폴더의 card-image-work/containment/*.original.cs에 보존한다.
