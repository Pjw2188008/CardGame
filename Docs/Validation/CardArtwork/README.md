# 카드 이미지 교체 검증

2026-11-10, Unity 6000.0.74f1, Windows.

## 실제 확인

- 일반 52장 + 조커 2장 + UNKNOWN 3장, 총 57개 이미지가 각 CardID에 정확히 연결되는지 검사했다.
- 각 카드에서 원본 Texture 표시, 실제 모델의 마나·공격력·설명 표시, 투명한 배경과 속 빈 강조 테두리를 검사했다. 현재/최대 체력의 실시간 값과 증가/피해 색상은 기존 포커 검사에도 포함된다.
- 최종 Unity UI 검사 659개 통과, 실패/예외 0: 카드 아트/공격 217, 드래그 58, PvP 26, 조커 사건 107, 문양 맵/배경 80, 포커 134, 손패/설정 37. 개별 JSON과 ChecksSummary를 보존한다.
- 1280×720과 1920×1080에서 일반·조커·UNKNOWN을 섞은 손패/필드의 실제 렌더를 생성했다. 1920 결과를 직접 확인했다. 첫 렌더에서 발견한 강조 색상 채움과 텍스트 잘림을 보완한 뒤 다시 검사했다.
- 손패/필드 입력 영역을 유지하고 실제 드래그·공격·조합 회귀를 통과했다. PvP 화면 검사도 기존 문양 텍스트 대신 실제 카드 Texture로 양쪽 필드의 식별을 확인한다.

## 범위 및 보존

기존 카드 규칙/마나/능력/공격·체력 계산은 수정하지 않았다. 원본 PNG, Import 설정, 씬과 NetworkManager를 삭제하거나 교체하지 않았다. 비공개 손패는 기존처럼 가린다. 실제 Relay 접속, 서로 다른 PC 사이 연결, 튜토리얼 전체 실습과 모든 기기/화면 비율은 이번에 재실행하지 않았다. 작은 손패의 긴 능력 설명은 축소 표시되며 기존 툴팁에서 상세 내용을 볼 수 있다.

수정 전 소스는 현재 작업 폴더의 `card-image-work/original`에 백업했다. 프로젝트 외부 파일 변경 권한이 필요한 작업은 기존 Unity 프로젝트를 명시하여 적용했다.

Windows Development Build 성공: 오류 0, 경고 8, 정상 종료 코드 0. 새 빌드는 `Builds/UNKNOWN-CardArtwork/UNKNOWN.exe`다. 복사본과 빌드 출력 DLL 해시 일치를 확인했고 BuildSummary에 기록했다. 수정 C# 11개와 원본 PNG 57개도 작업/검증 프로젝트에서 해시가 일치한다.
