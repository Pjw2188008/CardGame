# UNKNOWN 카드 전투 프로토타입

## 실행

`Assets/Scenes/UNKNOWN_Battle_Test.unity`를 열고 **Play**를 누른다. 또는 `UNKNOWN > Battle > Open Local Battle Test` 메뉴로 연다. 카메라를 보존하고 `UNKNOWN Battle Prototype`에 BattleUIController를 연결했다. Canvas, UI, EventSystem은 Play 시 생성되므로 별도의 Inspector 연결이 필요 없다. 네트워크 연결이나 Cloud 로그인이 필요 없다.

기존 SampleScene, NetworkManager, Relay 및 패키지는 이번 전투 구현에서 변경하지 않았다. 전투 씬을 기본 빌드 시작 씬으로 자동 변경하지도 않았다.

화면 아래쪽이 **현재 턴 플레이어**다. 턴이 바뀌면 두 필드의 위/아래 위치도 바뀐다.

1. 패의 카드를 선택하고 아래 필드의 빈 슬롯을 누르면 소환한다.
2. 소환 효과 대상이 필요하면 금색 테두리의 유닛을 선택한다. 연쇄 피해는 서로 다른 적을 순서대로 선택한다.
3. 다음 자신의 턴에 초록 테두리 유닛을 선택하고 적 유닛을 누르면 공격한다.
4. 상대 필드가 비었으면 **상대 플레이어 직접 공격** 버튼을 누른다.
5. **턴 종료** 후 화면을 넘기고 **준비 완료 · 턴 시작**을 누른다. 교대 화면은 패를 가린다.
6. 체력이 0이 된 플레이어가 패배한다. **새 게임**으로 초기화할 수 있다.

패가 9~10장이면 패 영역을 가로로 드래그해 나머지 카드를 확인할 수 있다. 선택한 카드의 설명은 패 바로 위에도 표시한다. 중앙에는 현재 턴·조작 결과·최근 전투 로그를 표시하고 오른쪽 전투 로그는 최근 13줄, 게임 상태에는 최근 100줄을 유지한다. 효과 발생 시 중앙 구분선이 잠시 강조된다.

## UNKNOWN 조합

**UNKNOWN 조합** → 패에서 **A** → **J/Q/K** → 오른쪽 결과 미리보기 확인 → **UNKNOWN 조합 확정** 순서다. 문양은 무관하다. 선택 취소로 재료 선택을 해제할 수 있고, 확정 전에는 카드가 소모되지 않는다.

재료는 패에 있어야 하며 필드 카드는 사용할 수 없다. 생성 횟수는 각 플레이어별 최대 3회이고 소멸/파괴되어도 회복되지 않는다. 조합 자체는 소환 횟수를 쓰지 않는다. 완성된 UNKNOWN을 소환할 때 해당 비용(7/8/9 MP)을 소모한다. 턴당 1회 소환 제한은 제거되었다.

## 조커

패의 **JOKER** → 자신의 필드 유닛 → **조커 도박 실행**. 성공/실패는 실제 규칙 계층에서 50%로 결정한다. 성공하면 공격력·최대 체력을 각각 1.5배 올림하며, 최대 체력 증가분만큼 현재 체력이 오른다. 실패하면 해당 유닛을 즉시 파괴한다. 조커는 어느 결과든 소모된다. UNKNOWN에도 쓸 수 있고 같은 유닛에는 한 번만 사용할 수 있다. 잘못된 대상에는 조커를 소모하지 않는다.

## 구현한 데이터와 규칙 해석

- 일반 52장 + 서로 다른 ID의 조커 2장 = 각 플레이어 54장 덱. UNKNOWN 3종은 조합으로만 생성한다.
- 30 체력, 시작 패 5장, 매 턴 시작 1장 드로우. 첫 플레이어도 첫 턴 시작 드로우를 받아 최초 화면에서 6장이다.
- 패 제한 10장. 가득 차면 덱에서 뽑은 카드를 버린다. 덱이 비면 드로우만 생략한다. 별도 탈진 피해 규칙은 추가하지 않았다.
- 필드 5칸, 마나가 충분한 만큼 여러 유닛을 소환할 수 있다. Inspector의 `Field Slots`와 BattleConfig에서 설정 가능하다.
- 소환 효과의 ‘자신’은 소환 유닛, ‘적/아군’은 필드 유닛이다. 효과 피해로 플레이어를 직접 지정하지 않는다. 아군 전체에는 소환한 자신도 포함한다.
- 선택 대상이 없으면 그 효과만 생략한다. 공격력은 0 이상, 회복은 최대 체력 이하, 최대 체력 증가 시 현재 체력도 동일하게 증가한다.
- 같은 카드의 ‘적 1명 피해 + 공격 감소’ 또는 ‘아군 1명 공격/체력 증가’는 처음 고른 **같은 대상**에 순서대로 적용한다. 중간에 죽으면 해당 대상의 후속 효과를 생략하며 다른 대상으로 바꾸지 않는다.
- 자해로 소환 유닛이 죽으면 나머지 소환 효과를 취소한다. 이미 확정한 소환의 대상 선택은 취소하여 효과를 우회할 수 없다.
- 하트의 ‘피해 N, 자신 회복 N’은 표에 적힌 고정 회복량을 적용한다. 실제 피해만큼 회복하는 별도 Lifesteal과 SwapStats는 현 데이터에 사용되지 않아 추가 구현하지 않았다.
- 각 플레이어의 패/덱은 별도 인스턴스이며 카드 원본 정의는 불변이다. 턴 소유권·대상 유효성·중복 행동은 BattleEngine이 검증한다.

## 디버그

- **패 공개 디버그**: 상대 패의 물음표 대신 카드 이름을 표시하고 턴 교대 가림 화면을 생략한다. 기본 OFF.
- Inspector **Seed**: 0이면 매 게임 새 시드, 양수 등 고정값이면 같은 덱 순서를 재현한다.
- 조합/조커 즉시 시험: Play를 멈추고 UNKNOWN Battle Prototype의 Seed를 **10**으로 지정한 후 Play. P1 최초 패는 ♣K, ♣2, JOKER, ♥A, ♥J, ♠3이다. A+J 또는 A+K를 조합한 뒤 마나가 충분해진 턴에 UNKNOWN을 소환하고 효과를 완료한 다음 조커를 그 유닛에 사용할 수 있다. 첫 턴에는 3 MP이므로 고비용 카드를 바로 소환할 수 없다. 기본값 0으로 돌리면 다시 무작위 게임이다. 일반 모드의 덱에 카드를 임의로 더하지 않는다.

## 코드 구조와 온라인 확장

| 파일 | 책임 |
| --- | --- |
| `CardData.cs` | CardDefinition, CardInstance, 54장 기본 덱 및 UNKNOWN 정의 |
| `BattleEngine.cs` | 턴, 패/덱/필드, 공격·효과 큐, 조합, 조커, 승패 |
| `BattleUIController.cs` | Canvas 구성, 카드 선택, 미리보기, 핫시트 패 가림, 화면 갱신 |
| `BattleSetupMenu.cs` | 전투 씬 열기 및 진입 컴포넌트 복구 메뉴 |

규칙 파일 두 개에는 UnityEngine 의존성이 없다. 무작위 처리는 IRandomSource로 주입하며 기본 SeededRandom을 사용한다. UI는 Summon/Attack/SelectEffectTarget/Combine/Gamble/EndTurn 명령을 보낼 뿐 게임 상태를 수정하지 않는다. 명령에는 actor 번호가 있으므로 이후 NGO Host가 검증하고 상태를 전송하는 계층을 붙일 수 있다. 현재는 네트워크 직렬화나 온라인 권한 검증/전투 동기화를 구현하지 않았다.

## 자동 검증

프로젝트 루트에서 다음 명령을 실행한다. Unity가 다른 위치에 설치되어 있다면 Editor/Data 경로를 첫 인자로 전달한다.

```powershell
cmd /c Tests\UNKNOWN\Run-BattleTests.cmd
```

Unity에 포함된 C# 컴파일러와 Mono를 사용한다. 추가 패키지를 설치하지 않고 출력은 임시 폴더에 둔다. 실행 정책이 허용된 환경에서는 같은 폴더의 Run-BattleTests.ps1도 사용할 수 있다. 테스트는 Assets 밖에 있어 플레이어 빌드에 포함되지 않는다.

**58개 테스트 통과, 실패 0개.** (마나·타이머·이벤트 검증 추가)

검증 범위: 일반 52장과 UNKNOWN 3종의 모든 수치/효과/순서 대조, 덱/초기 패/독립 인스턴스, 시드 재현, 턴 소유권, 소환/필드 제한, 소환 대기, 턴당 1공격, 동시 반격/파괴, 직접 공격 제한, 승패 이후 명령 차단, 패 초과/빈 덱, 유효 대상 선택, 동일 대상 후속 효과, 파괴된 대상 처리, 회복/공격 감소/최대 체력/자해, 연쇄/무작위/드로우/버리기, UNKNOWN 조합/생성 제한, 조커 성공/실패/중복 제한, 모든 소환 정의의 효과 완료, 12개 시드 자동 대전 중 상태 불변식.

## 에디터 확인

자동 테스트는 모델 검증이며 화면/입력 검증과 구분한다. Game 뷰를 Full HD 또는 16:9로 두고 필요하면 최대화한다. 외부 이미지나 TMP 리소스를 요구하지 않도록 기본 UGUI Text와 운영체제 한글 글꼴을 사용했다.

씬을 Windows 빌드에 포함하려면 Build Profiles의 Scene List에 UNKNOWN_Battle_Test를 추가하고 시작 씬으로 선택한다. 기존 방 연결 씬의 시작 순서는 자동으로 변경하지 않는다.

### 이번 에디터 실측 결과

Unity 6000.0.74f1에서 Play 진입과 Canvas 생성을 확인했다. 마우스로 ♦10 선택 → 슬롯 소환 → 턴 종료 → 패 가림 화면 → P2 턴 시작 → ♥7 소환 → 적 ♦10 선택 → 피해 3 및 자기 회복 → 다음 자기 턴 공격 가능 강조 → ♦10으로 ♥7 공격 → 양쪽 유닛 동시 파괴까지 직접 확인했다. 패 수/덱 수/턴/공격 가능 상태와 로그가 갱신되었다.

UNKNOWN 조합·조커 성공/실패·게임 종료는 자동 규칙 테스트로 검증했다. 해당 UI 클릭 경로와 전체 승리까지의 수동 플레이, 다른 화면 비율/플랫폼에서의 시각 검증은 별도 확인 항목이다.
최종 Unity 에디터 컴파일 후 Console 오류 0개·경고 0개를 확인했다.

마나·60초 타이머·문양별 이펙트가 추가되었다. 최신 규칙과 실행/검증 결과는 [통합 안내](UNKNOWN-Mana-Timer-FX.md)를 참고한다. 최신 자동 검증은 규칙 58개와 실제 Play Mode 확인 36개 통과, 런타임 오류 0개다. 이전 문단의 미검증 기록은 초기 버전 기준이며 현재 조합·조커·승패 UI 경로는 Play Mode 통합 검사에서 실행했다.
