# 카드 호버 확대 미리보기

2026-11-10, Unity 6000.0.74f1.

카드에 마우스를 올리면 원래 입력용 카드를 유지하고 옆에 약 2배 크기의 카드 미리보기와 기존 상세 정보를 함께 표시한다. 미리보기의 그림/마나/공격력/현재 체력/설명은 원본 카드 데이터를 사용한다. 큰 카드에서는 텍스트도 비례해 커진다. 기존 손패·필드 카드의 기본 크기는 바꾸지 않는다.

미리보기는 모든 Graphic의 Raycast와 상호작용을 꺼서 클릭/드래그를 가로채지 않는다. 마우스를 떼거나 카드·공격 드래그, 메뉴 전환, 카드 뷰 제거 등이 발생하면 기존 HideTooltip 경로로 닫힌다. 뷰포트 안으로 위치를 제한하고 조합/맵 툴팁은 기존 작은 텍스트 형태로 복원한다. 비공개 상대 손패에는 새 앞면을 생성하지 않는다.

새 검사는 실제 PointerEnter/Exit 이벤트, 원본 카드의 클릭 대상 유지, 소환/공격 드래그 시 닫힘, 공개 상대 카드 보기, 뷰포트 가장자리 제한, 조합/맵 툴팁 복원 및 숨김 손패를 포함한다. 1280×720과 1920×1080 실제 렌더를 생성하고 확대 카드와 상세 정보 표시를 직접 확인했다.

기존 게임 규칙과 네트워크 연결 구조는 수정하지 않았다. 실제 Relay 연결 및 튜토리얼 전체 실습은 이번에 다시 실행하지 않았다. 검사 결과는 JSON과 ChecksSummary에 보존한다. 수정 전 기존 파일은 현재 작업 폴더의 card-image-work/hover-preview/*.original.cs에 보존한다.

최종 UI 검사 757 개 통과, 실패/예외 0. 카드/공격 311, 드래그 58, PvP 26, 조커 107, 문양 맵 80, 포커/수치 138, 손패/설정 37. 수정 C# 6개의 작업/검증 프로젝트 해시가 일치한다.

Windows Development Build 성공: 오류 0, 경고 8, 정상 종료 코드 0. Builds/UNKNOWN-CardHover/UNKNOWN.exe와 폴더 전체를 사용한다. 복사본과 빌드 출력 DLL의 해시 일치를 확인했으며 BuildSummary에 기록했다. 기존 빌드는 유지했다.
