# 현재 체력 표시 및 카드 배지 숫자 정렬

2026-11-10, Unity 6000.0.74f1.

카드 체력은 현재 값만 표시한다. 예: 10 → 피해 2 후 8 → 회복 1 후 9. 체력 증가도 기존 CardInstance.CurrentHP의 실제 값으로 갱신한다. 최대 체력, 회복 제한과 능력치 계산 자체는 변경하지 않는다. 상세 정보는 기존 툴팁에서 확인한다.

마나·공격력·체력 Text에 CardBadgeCenter 메시 효과를 적용한다. 폰트의 행간/여백으로 생기는 오차를 피하고 실제 보이는 숫자(그림자 포함)의 메시 경계를 배지 중앙에 맞춘다. 카드 이미지 비율과 크기가 바뀌면 기존 CardArtLayout이 정렬 영역과 글씨 크기를 갱신한다. 조커의 마나 보석은 일반 카드와 다른 이미지 위치를 사용한다. 이전에 제거한 추가 테두리는 계속 표시하지 않는다.
