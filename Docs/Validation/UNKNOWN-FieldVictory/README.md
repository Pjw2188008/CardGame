# UNKNOWN 필드 3장 승리 검증

2026-11-08, Unity 6000.0.74f1, Windows.

## 규칙 변경

생성 누적 승리를 제거하고, 자기 필드의 살아 있는 UNKNOWN 3장을 기준으로 승리한다. 손패와 파괴/폐기된 카드는 승리 진행도에 포함하지 않는다. 소환 효과 완료 후 판정한다. 파괴되거나 버린 UNKNOWN은 현재 보유 제한에서도 제외하여 재조합할 수 있다. 누적 생성 이력은 카드 수 보존 검사에만 유지한다. 일반/문양 맵의 HP 0 승리와 조커 맵의 기존 승리 조건을 유지한다.

상세 설계와 변경 이유는 `../../UNKNOWN-FieldVictory.md`에 기록했다.

## 완료한 검사

- `Rules.txt`: 189개 통과, 실패 0. 손패만 3장일 때 미승리, 각 플레이어의 실제 세 번째 필드 소환 승리, 효과 대상 대기 중 미승리, 효과 완료 전 파괴 시 미승리, 전투/도박 실패의 진행도 감소, 파괴 후 재조합, 조커 맵 예외와 Snapshot의 개인 진행도를 검사했다.
- 3난이도 × 5맵 × 3시드 AI 대전 45경기 모두 종료, 5,299행동. 불법 명령, 마나/손패 제한, 카드 수/ID 보존 검사를 통과했다. NORMAL 상대 HARD 표본은 17승 3패이며 이번 작업의 승리 규칙 검증에 딸린 참고 수치다.
- Unity AI 대전 UI 43개 통과, 실패/예외 0.
- Unity 튜토리얼 UI 38개 통과, 실패/예외 0. 실제 UNKNOWN 드래그/소환 후 7단계 완료를 확인했다. 첫 실행에서 기존 7단계 드래그 제한으로 타임아웃이 발생했고, UNKNOWN 카드의 드래그를 허용한 뒤 재실행했다.
- 기존 전투 UI 회귀 455개 통과, 실패/예외 0: 공격 43, 드래그 58, PvP 26, 조커 사건 107, 문양 맵 50, 포커 134, 손패/설정 37. PvP는 손패 3장 미승리와 3장 실제 소환 후 양쪽 진행도·승리 화면을 Unity JSON 왕복으로 확인한다. 개별 JSON과 `ChecksSummary.json`을 보존했다.
- 작업 프로젝트의 실제 패키지 참조로 런타임/Editor Roslyn 컴파일 성공. 검사용 DLL은 Library의 별도 경로에 생성했다.
- `SourceManifest.json`은 수정한 C# 소스와 격리 Unity 프로젝트의 해시 일치를 기록한다. 원본 프로젝트의 씬/NetworkManager는 새로 만들지 않았다.
- Windows Development Build 성공, 오류 0/경고 8, Unity 정상 종료 코드 0. `Builds/UNKNOWN-FieldVictory/UNKNOWN.exe`와 폴더 전체를 사용한다. `BuildSummary.json`에 DLL SHA256을 기록하고 검증 프로젝트 출력과 복사본의 해시 일치를 확인했다. 기존 빌드 폴더는 보존했다.

## 범위

온라인 UI 검사는 Host 규칙 엔진의 Snapshot을 Unity JSON으로 직렬화/복원하여 양쪽 화면과 승패를 비교한다. 이번 작업에서 실제 Relay 두 프로세스 접속과 서로 다른 PC 간 접속을 재실행하지 않았다. 새 Windows 빌드에서 사람이 직접 장기 플레이한 결과와 난이도 체감도 검증하지 않았다. 온라인 플레이 시 양쪽 모두 같은 새 버전을 사용해야 한다.
